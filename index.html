🌱 Elastic Bean

Welcome to Elastic Bean! This is a comprehensive guide to help you get started with creating and deploying applications using AWS Elastic Beanstalk. Elastic Bean simplifies the process of deploying web applications and services to the cloud, handling the infrastructure so you can focus on your code.

✓ First Version for Elastic Bean

Steps to Create Elastic Bean

Step 1: Install AWS CLI

First, you need to install the AWS Command Line Interface (CLI) on your machine.

pip install awscli

Verify the installation with: aws --version

Step 2: Configure AWS Credentials

Set up your AWS credentials using:

aws configure

You'll be prompted to enter your AWS Access Key ID, Secret Access Key, default region, and output format.

Step 3: Install Elastic Beanstalk CLI

Install the Elastic Beanstalk command line tool:

pip install awsebcli

Verify with: eb --version

Step 4: Create Your Application

Prepare your application code in a directory. For a Python app, create a simple structure:

application.py or app.py

Make sure your application listens on port 5000 or configure the appropriate port.

Step 5: Initialize Elastic Beanstalk

Navigate to your application directory and initialize Elastic Beanstalk:

eb init -p python-3.9 my-app

Choose your default region and other preferences when prompted.

Step 6: Create an Environment

Create an Elastic Beanstalk environment for your application:

eb create production-env

This will set up the necessary AWS resources (EC2 instances, load balancers, etc.)

Step 7: Deploy Your Application

Deploy your code to the environment:

eb deploy

Your application will be uploaded and deployed automatically.

Step 8: Open Your Application

View your deployed application in the browser:

eb open

This will automatically open your application URL in your default browser.

Step 9: Monitor Your Application

Check the health and logs of your application:

eb health - View environment health

eb logs - View application logs

Step 10: Clean Up

When done, terminate your environment to avoid incurring charges:

eb terminate production-env
